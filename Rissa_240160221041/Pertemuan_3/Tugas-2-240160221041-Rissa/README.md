# Sistem Absensi Organisasi — API Sederhana (Node.js Native)

Project HTTP Server sederhana menggunakan Node.js tanpa framework Express.js. Project ini menerapkan modul ESM, *environment variable*, helper response JSON, serta pembacaan berkas secara *asynchronous*.

---

## 📁 Struktur Project

```text
├── data/
│   └── absensi.json    # Data absensi berbentuk JSON
├── config.js           # Konfigurasi aplikasi via environment variables
├── server.js           # Native HTTP Server dan routing
├── README.md           # Panduan penggunaan & dokumentasi project
└── refleksi.md         # Catatan refleksi pengembangan dan penggunaan AI
