# Refleksi Tugas 1 Pertemuan 2

Setelah mengerjakan Tugas 1 tentang refactor dan mini-service, ada beberapa fitur JavaScript pada Pertemuan 2 yang cukup mengubah cara saya menulis kode.

Pertama, **arrow function** membuat penulisan fungsi menjadi lebih singkat dan sederhana. Dibandingkan menggunakan `function`, arrow function membuat kode lebih ringkas sehingga lebih mudah dibaca.

Kedua, **destructuring dan template literal** membuat pengolahan data menjadi lebih praktis. Dengan destructuring, saya bisa mengambil nilai dari object tanpa harus menuliskan nama object berulang kali. Template literal juga memudahkan ketika ingin menggabungkan data ke dalam sebuah teks.

Ketiga, **async/await dan Promise** membuat saya lebih memahami bagaimana proses asynchronous bekerja pada JavaScript. Pada mini-service ini, saya menggunakan async/await untuk menjalankan fungsi `findAll`, `findById`, `create`, `update`, dan `delete` yang memiliki simulasi waktu tunda.

Hal yang masih cukup membingungkan bagi saya adalah memahami perbedaan penggunaan `Promise.all()` dengan menjalankan beberapa proses asynchronous secara satu per satu. Saya masih perlu lebih banyak latihan agar lebih memahami kapan penggunaan `Promise.all()` lebih sesuai.
